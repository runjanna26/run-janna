# Run Janna — Portfolio

Personal portfolio site for Run Janna, Robotics & AI researcher at VISTEC, published via GitHub Pages:
https://runjanna26.github.io/run-janna/

## Structure

```
index.html              Single-page site (About, Projects, Publications, Contact)
assets/css/style.css     Site styles
assets/js/main.js        Nav/back-to-top/carousel behavior
figure/                  Profile photos, background, project logos
highlights/              Highlight-carousel photos
icons/                   Small icons (schools, socials)
googlec...html           Google Search Console site-verification file (keep at root)
```

## Editing

The site is static — edit `index.html`, `assets/css/style.css`, or `assets/js/main.js` and push to `main`; GitHub Pages redeploys automatically.
